## 结论

1. **线上 ReAct 召回应报 0.963±0.014（5 次采样，范围 0.950–0.983），不报单次 0.983。**
   预注册线 0.96 恰好落在噪声带内：5 次里 3 次低于、2 次高于，"过线"不再是确定结论，只是均值勉强过。

2. **波动集中在 2/30 道题，且全是可解释推理切片。** id9（公司法第264条）、id10（公司法第116条）
   各丢一条跨法域 primary；v20 的 id9=1.0 是运气不是常态（4/5 次都丢）。
   该切片真实水平 0.725±0.105——不是偶发回退，是系统性弱点。

3. **失败模式和 id7 一致：跨法域题里被主导法域挤掉的 secondary-domain 条文。**
   id7 稳缺劳动法第19条（公司法第53条占排），id9/id10 概率性缺公司法条文。
   三道题的共同结构：原查询+扩展变体都偏向一个法域，缺口查询能否补到另一法域看运气。
   这是下一步修法的目标，不是方差问题本身。

4. **其余 28 题五次采样完全一致**：显性/隐性事实、对抗、复合切片 1.000±0.000，
   trap_primary 3/3 次次命中。轮数在 5 道题上有波动（id1/8/15/28/30）但不影响召回。

5. **可选的止血方案（未实施）**：缺口查询生成后显式检查 top-10 覆盖的法域、对缺失法域补检；
   或把 lane fetch 从 20 提到 30 提高尾部条文入池率。改任何一处都要重测方差。
