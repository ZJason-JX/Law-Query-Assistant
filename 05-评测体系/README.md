# 05 · 评测体系

## 这一阶段要回答的问题

**怎么量化「这个回答可信」，并且让每一次改动都有预注册的门禁可过？**

## 结论与决策

| 项 | 结论 |
|---|---|
| 1.0 | 人工 MOS **三分制（0–2）** 五维；20 题分层（显性 60% / 隐性 25% / 可解释 10% / 对抗 5%）；Agent 阶段单轮 25 + 多轮 25 |
| 2.0 | **五分制（1–5）+ LLM-as-judge**（qwen-plus，±1 一致率 86.7%、Pearson 0.893）+ **预注册门禁**（显性 ≥0.90 / 隐性 ≥0.70 / 对抗一票否决）+ 回归脚本 |
| ⚠️ 口径提醒 | **1.0 的 2.00 与 2.0 的 4.46 是不同量纲，不可直接比较；1.0 单部民法典与 2.0 六部法也不共基线** |
| 当前关键值 | 检索 mean **0.983** · 生成 MOS **4.46** · 六版**零 outside_context** · 意图 **0.800** |
