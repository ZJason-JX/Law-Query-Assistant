# 04 · 架构设计

## 这一阶段要回答的问题

**用什么系统结构兑现三段式 + 可追溯 + 熔断，哪些组件该用生成模型、哪些不该？**

## 结论与决策

| 项 | 结论 |
|---|---|
| 1.0 | Coze 平台上的 **Agentic RAG 工作流**（意图拆解 → 知识库召回 → 生成 → 安全校验） |
| 2.0 | **S0–S5 状态机**：意图路由 → 首轮检索 → 充分性门控 → 追加轮 ≤2 → 生成 → 引用校验 |
| 选型判断 1 | 生成用 LLM、判断用 **JEV 决策模型**（按任务类型选原语） |
| 选型判断 2 | **法条级切分**对齐引用单元（法条号 = chunk id，溯源退化为字符串比对） |
| 选型判断 3 | **reranker 两次负优化后永久弃用**（写进黑名单） |
| 技术栈形式 | Python 核心链路 + 低代码外围的**混合栈** |
