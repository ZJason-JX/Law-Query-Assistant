# 02 · 竞品分析

## 这一阶段要回答的问题

**市面产品答同一批法律问题时差在哪，我们的差异化落点凭什么成立？**

## 结论与决策

| 项 | 结论 |
|---|---|
| 竞品对比 | 15 个相同 Query 对比法智与豆包：**竞品普遍给结论、不给法条编号与出处** |
| 模型横评（三分制） | DeepSeek V3.1 **1.35** / ERNIE 3.5 **1.64** / ERNIE 4.0 **1.67** |
| 横评形态 | DeepSeek 拒答率 >25% 但无根据回答率 0；ERNIE 3.5 每题都答、低分答案多 |
| 差异化落点 | **引用可追溯 + 零召回拒答** |
