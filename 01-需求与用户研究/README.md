# 01 · 需求与用户研究

## 这一阶段要回答的问题

**用户是谁、在什么场景下查法条、他们真正的痛点能否直接约束回答的格式？**

## 结论与决策

| 项 | 结论 |
|---|---|
| 用户分层（20 人问卷） | 临时查 50% / 定期查 25% / 专业查 25% |
| 三条痛点 | 法条晦涩 · 信息源混乱易混入过期内容 · 搜索结果抓不住重点 |
| 痛点 → 产品决策 | 第三条（抓不住重点）直接定义了**三段式回答格式**（引用法条 → 通俗解释 → 行为指导） |
| 诚实标注 | 2.0 沿用 1.0 的用户分层，**未重新做调研**（已知缺口） |
