## 📌 项目背景

法律文本晦涩、条款之间有复杂的层级与冲突关系，非专业人士很难精准定位适用法条；通用大模型直接作答又容易产生"法律幻觉"。

本项目以《中华人民共和国民法典》为知识库，构建 **RAG 检索 + Agent 意图拆解 + 大模型生成** 的问答链路：用户用自然语言提问，系统返回**通俗解释 + 可追溯的法条依据 + 实务指引**。

> 项目从 0 到 1 独立完成：竞品与用户调研 → 场景与产品定义 → Agent 架构设计 → 评测体系构建 → Badcase 归因迭代，并在 Coze 低代码平台完整复现，验证方案可迁移性。

## ✨ 核心特性

| | 特性 | 说明 |
|---|---|---|
| 🎯 | **语义穿透召回** | 支持从"隐性事实"与"多重法律关系"中提取争议焦点并映射到对应法条 |
| 🧩 | **结构化法理解析** | 严格遵循「法条引用 → 法理释明 → 实务指引」三段式输出，自动拆解法定构成要件与优先适用规则 |
| 🛡️ | **安全熔断机制** | 零召回时强制阻断生成，杜绝模型凭空编造法条的合规风险 |
| 🔁 | **轮次受控的多轮交互** | 通过 Function Calling 限制对话轮次，避免多轮发散 |
| 📊 | **可量化的评测闭环** | 自带分层评测集 + 五维度 MOS 评测 + Badcase 归因表 |

## 🏗️ 系统架构

![架构图](docs/agentic-rag-workflow.png)

> 图片待补充：将 Coze 工作流截图保存为 `docs/agentic-rag-workflow.png` 即可自动显示。

**主对话流**：用户输入 → 意图识别 → 任务拆解 → 知识库多路召回 → 答案生成 → 安全校验 → 结构化输出

**知识处理流**：法条文档解析 → 按"编-章-节-条"逻辑切片 → Embedding → 向量化入库

**决策要点**：
- **意图识别 / 任务拆解**：Doubao-1.5-pro（轻量、快）
- **答案生成**：Doubao-2.0-pro（质量优先）
- **关键参数**：召回阈值 0.35、召回数 4、切片与 Embedding 经控制变量法调优

## 🔬 关键工作

<details>
<summary><b>① 竞品与用户调研</b></summary>

对比法智、豆包等主流 AI 法律产品，围绕**问题理解 / 检索准确性 / 可解释性 / 安全性**四维度设计 15 个典型 Query，输出竞品体验分析报告。

问卷调研 20 名不同背景用户（企业、政府、法律），发现分层需求：
- 普通用户 → 需要**通俗解释**
- 专业用户 → 需要**精准法条定位**
- 合规场景 → 最关心**回答安全性**

</details>

<details>
<summary><b>② 场景定义与产品方案</b></summary>

将产品拆解为四大核心场景，逐类定义"理想回答标准"：

`构成要件与归责` · `法条精准检索` · `规则冲突与适用` · `法律概念界定`

</details>

<details>
<summary><b>③ 评测体系构建</b></summary>

- **五维度 MOS 评测**（0–2 分）：准确性 / 相关性 / 完整性 / 简洁性 / 安全性
- **评测集分层**：显性问题 60% · 隐性问题 25% · 可解释性 10% · 对抗样本 5%
- Agent 阶段扩展为：单轮 25 条 + 多轮 25 条
- 参照基准：以 Gemini 反推"应召回法条"作为召回黄金集

</details>

<details>
<summary><b>④ Badcase 归因与策略调优</b></summary>

| 环节 | 归因分类 | 对应调优动作 |
|---|---|---|
| 召回侧 | 阈值不当 / 切片不合理 / Embedding 适应性差 | 阈值 0.1 → 0.35、召回数 10 → 4、更换 Embedding、重设切片长度 |
| 生成侧 | 意图拆解失败 / 回答幻觉 | Prompt 工程迭代、模型重新选型、零召回熔断 |

</details>

## 🚀 v2.0 升级路线（进行中 · 2026.09 启动）

### 1️⃣ 意图识别层 → JEV 决策模型

[JEV](https://typesafe.ai) 由前 OpenAI 研究员 **Diogo Almeida**（ChatGPT / RLHF 核心研发成员）创办的 **TypeSafe AI** 于 2026 年 9 月发布，是一类全新的 **System One 决策模型**：

- ❌ **不生成文本**，直接输出结构化判定 + 校准置信概率（如 `意图=法条精准检索, p=0.93`）
- ⚡ 响应 70–500ms，官方称较主流大模型快 **20–200 倍**、成本低 **40–400 倍**
- 🛡️ 输出空间受限 → 从机制上规避生成式幻觉
- 🎓 训练方法：纯合成数据 + RLCD（reinforcement learning from calibrated decisions）

**在本项目中的落点**：把"快判断"从昂贵的生成式模型中剥离，让大模型只承担"慢思考"的答案生成 —— 即 Agent 架构的**快慢分工**：

1. 四大法律场景的**意图分类与工具调用选择**
2. **置信度阈值路由**：低置信时自动改走多路召回或转人工兜底
3. **Agent 行为与安全风险监控**
4. **多模型路由**决策

> ⚠️ 现状说明：JEV 目前尚未对中国大陆地区开放；过渡方案为采用社区开源复现（MIT 协议）在本地离线部署验证。

### 2️⃣ 结构化向量库

法条从"非结构化文本切片"升级为「**条款编号 — 层级关系 — 要件要素**」结构化入库，支撑**精准到款**的定位与跨条款关联检索。

### 3️⃣ 自动化评测流水线

把人工 MOS 评测升级为脚本化批量回归评测：每次调参自动产出指标对比报告，显著缩短迭代周期。
