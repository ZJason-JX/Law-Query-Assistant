# 03 · 场景定义与产品方案

## 这一阶段要回答的问题

**四类典型场景下，一份「能交付给用户」的法律回答应该长什么样、哪里必须熔断？**

## 结论与决策

| 项 | 结论 |
|---|---|
| 回答格式 | 四场景理想态 → **三段式**：引用法条 → 法理释明 → 实务指引 |
| 安全边界 | 零召回强制熔断 + Function Calling 限制轮次 |
| 2.0 演进 | 沿用三段式，另加**选条通则**与**信息密度硬约束**（v1.2 冻结） |
