# case-02 · 生成三版迭代

## 1. 现象

生成 MOS 卡在 4.26（v1.0），完整性维度拖后腿：多路意图共用一套生成模板，长 prompt 稀释指令、选条不准。

## 2. 归因

单一大 prompt 装不下六类意图的差异化约束；模板需要按意图拆分（每路一个文件），并且需要更硬的选条与密度规则。

## 3. 假设

- v1.1：四合一模板重构（合并冗余指令、强化三段式）；
- v1.2：加「选条通则」+「信息密度硬约束」。**预注册时预判**：简洁性收紧必然牺牲完整性，两者此消彼长。

## 4. 预注册门禁

五维 MOS 各维不劣于上一版即放行；prompt 文件 hash 记入评测报告，保证可复现。

## 5. 实验结果

| 版本 | MOS | 说明 |
|---|---|---|
| v1.0 | 4.26 | 基线（共用模板） |
| v1.1 | 4.34 | 四合一重构 |
| **v1.2** | **4.46 / 4.37**（两次跑批） | 选条通则 + 密度约束，**采纳冻结** |

**关键发现**：「简洁性收紧必然牺牲完整性」的预判被数据推翻——两者同升。密度约束没有压掉完整度，反而靠选条通则减少了无效引用。
