# case-01 · 检索九版消融

## 1. 现象

检索召回不达标：v0 基线隐性切片召回 **0.50**（隐性事实题），隐性事实切片大量漏召，后续所有生成质量都被检索上限锁死。

## 2. 归因

分块策略破坏法条完整性（1.0 定长 500 字切片的遗留问题）+ 单路 dense 检索覆盖不足 + 无查询扩展。归因明细见 [`召回过程Badcase.xlsx`](../召回过程Badcase.xlsx) 与 [`召回Badcase归因总结.xlsx`](../召回Badcase归因总结.xlsx)。

## 3. 假设

按「先富化语料 → 再精排 → 再扩展召回」的顺序逐个验证假设，每版只动一个变量。

## 4. 预注册门禁

实验前注册：显性 ≥0.90 / 隐性 ≥0.70 / 对抗一票否决；实验后不为过线回头调参。

## 5. 实验结果

| 版本 | 隐性切片召回 | 结论 |
|---|---|---|
| v0 | 0.50 | 基线 |
| v0.1 富化 | 无效 | 否决 |
| v0.2 rerank | 0.40 | **负优化** |
| v0.3 | 0.60 | 但融合实现偏离 RRF 规格（见 case-04） |
| v0.4 | 0.40 | **负优化** |
| v0.5 / v0.5b | 0.50 / 0.60 | 平 |
| **v0.6-RRF** | **0.60 例外放行（隐性未达 0.70 门禁，由对抗 veto PASS + 显性全绿通过冻结，口径见白皮书 3.1）** | **采纳，冻结** |

**黑名单（被否决方向，留档防复发）**：reranker 精排、稀疏路加权、best-rank 融合主键。

## 6. 采纳或否决

采纳 v0.6-RRF（BGE-M3 dense/sparse 双路 + 查询扩展 + RRF k=60 求和融合），冻结决议见 [`05-评测体系/v2/FREEZE.md`](../../05-评测体系/v2/FREEZE.md)；引用审计六版结果见 [`05-评测体系/v2/citation_audit/`](../../05-评测体系/v2/citation_audit/)。
